A: List + Detail Panel

Left panel lists repos (like repoz output). Right panel shows detail for the selected repo — branches, commits, CI, PRs. Navigate with j/k, drill down with enter.

Pros

  • Familiar pattern (lazygit, k9s)
  • Clean separation of overview vs detail
  • Scales well with many repos

Cons

  • Less info visible at a glance
  • Need to navigate to see each repo

B: Expanded List (repoz-style)

Single scrollable view — each repo shows inline detail (commits, branches, CI). Basically repoz output but interactive. Select repos, act on them directly.

Pros

  • Everything visible at once
  • Closest to current repoz feel
  • No navigation needed for overview

Cons

  • Gets cramped with many repos
  • Less room for detailed info per repo
  • Harder to add complex features
